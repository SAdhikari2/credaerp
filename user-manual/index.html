    Before You Contact Support: I’m Stuck

    This section is designed for the moment you are looking at a screen and are unsure what to do next. Follow the matching situation, complete the checks in order, and avoid repeating a transaction until you know whether it was saved.

    🛑 The golden rule when something looks wrong

    Do not bill, purchase, return or save the same transaction again until you have checked history. Open Invoice History, Purchase Register or the relevant list first. A second save can create duplicate stock or duplicate accounting entries.

    🧭

    I don’t know where to click

    Use the task map above, or press the shortcut for the workspace you need:

    • F1 Sales / billing
    • F2 Purchases / procurement
    • F3 Advance orders
    • F8 Reports and analytics
    • F9 Inventory and stock

    If a shortcut does nothing, click once inside the application and try again. You can always use the visible menu instead.

    🔎

    I can’t find a medicine

    1. Search using the first few letters, not the full brand name.
    2. Try the generic name, alternate spelling or barcode.
    3. Check Inventory → Medicine Master.
    4. If it is missing, add it or use Bulk Import, then return to billing and search again.

    Still missing? Confirm you are in the correct store/company profile before importing the item.

    💾

    My bill will not save

    1. Read the red message beside the field; it usually identifies the missing value.
    2. Confirm a batch is selected for every medicine.
    3. Check quantity, selling price, customer type and payment mode.
    4. Remove the line and add it again if the batch has no available stock.
    5. Check whether the day is already closed.

    Before retrying: Search Invoice History in case the first click actually saved the bill.

    🖨️

    The printer did not print

    1. Do not create the bill again.
    2. Open POS → Invoice History.
    3. Find the latest invoice and choose Reprint.
    4. If it still fails, print a test page from the operating system and confirm the selected printer, paper size and connection.

    Remember: A printer problem does not automatically mean the invoice failed.

    📦

    My stock quantity is wrong

    1. Identify the exact medicine, batch and unit that is wrong.
    2. Check Invoice History for sales and Purchase Register for inward stock.
    3. Check Sales Returns and Purchase Returns before adjusting anything.
    4. Use Inventory → Stock Entry / Adjustment only for a verified physical count difference.

    Never fix stock by entering a fake purchase or sale. That changes your reports and tax data.

    🧾

    GST total or tax looks wrong

    1. Check the item’s HSN, tax rate and taxable value.
    2. Check whether the customer/vendor state makes the transaction CGST + SGST or IGST.
    3. Compare the line-level totals with the source invoice.
    4. Correct the master data, then re-enter only the transaction that is genuinely wrong.

    Do not manually force a tax total without identifying the line or master-data cause.

    🌙

    Day Closure is blocked

    1. Return to the POS screen and complete or cancel any held/open bill.
    2. Check that cash, UPI, card and credit totals match your physical records.
    3. Resolve any pending return or payment message shown by the screen.
    4. Run the closure again. Use the EOD Master Guide below if the difference remains.
    🔄

    The application looks frozen

    1. Wait briefly after a scan, report or save; large imports can take time.
    2. Do not click Save repeatedly.
    3. Check the relevant history list to see whether the action completed.
    4. If safe to do so, close and reopen the application, then verify the last transaction.
    5. If it repeats, open Support & Diagnostics and create a support bundle.
    🛡️

    Something is missing after restart

    1. Confirm you opened the same store/company profile and machine.
    2. Check the relevant history/register before assuming data was lost.
    3. Do not restore a backup over the current database until you know which copy is correct.
    4. Open Support & Diagnostics and generate a support bundle.

    If you still need help, send a useful support request

    Send the screen name, the exact action you clicked, the invoice/purchase number, the medicine or batch involved, the message shown, and a screenshot. Also mention whether the issue happens every time or only once. This lets support diagnose the problem without asking you to repeat the whole story.

    1. Getting Started: First 7 Days Guide

    Transitioning to a new ERP requires a structured approach. Follow this strict sequence to ensure your financial ledgers start correctly.

    Day 1: Setup & Initial Balances

    1. Pharmacy Profile: Navigate to System Settings → Company Profile. Enter your Pharmacy Name, accurate GSTIN, and Registered Address. This data prints on your invoices and GSTR-1 files.
    2. Populate Medicine Master: Use the Bulk Import tool to load your medicines.
    3. Enter Opening Stock: Go to Inventory → Stock Entry to map the physical boxes currently sitting on your shelves.
    ⚠️ Critical Constraint: Opening Stock vs. Purchase

    Never use the "Procurement / Purchase" screen to enter your initial existing shop stock.

    Purchases strictly create Vendor Payable ledgers and GST Input Tax Credit (ITC). If you enter old stock as a new purchase, your accounting will show that you owe massive amounts to suppliers, and your GST ITC will be artificially inflated. Always use Stock Entry for initial stock.

    💡 Scenario: I entered Opening Stock, but found a hidden box later

    If the financial year hasn't closed and you haven't filed GST for the month, you can safely go back to Inventory → Stock Entry and add the missing batch. The system uses a specific equity ledger (OPENING_BALANCE_EQUITY) which will safely absorb the addition without touching vendor accounts.

    2. The POS Terminal (Sales & Billing)

    The POS (Point of Sale) Terminal is the heart of CredaERP, designed for rapid, high-volume pharmacy billing. Press F1 anywhere in the software to instantly open the POS workspace. The workspace contains 5 powerful tabs.

    TAB 1

    📝 Create Invoice (The Billing Screen)

    This is where you spend 90% of your time, ringing up customers at the counter.

    Key Functionalities:
    • Smart Search: Type the first 3 letters of a medicine or scan its barcode. The system instantly pops up a list of available batches.
    • Batch Selection (FEFO): The system forces the cashier to pick the exact batch they are holding. (Real World Example: If you have Crocin Batch A expiring in 2026 and Batch B expiring in 2027, the cashier must pick Batch A to avoid dead stock losses.)
    • Multi-Pay (Split Tender): If a bill is Rs. 500, and the customer hands you a Rs. 200 note and wants to GPay the remaining Rs. 300, click the Multi-Pay button. Type 200 in Cash and 300 in UPI. This keeps your drawer perfectly balanced.
    • B2B Billing: If selling to a clinic, type the clinic's name in the Customer field. The system automatically converts the retail slip into a B2B Tax Invoice, segregating GST for their ITC claim.
    💊 Quantity Logic (Strips vs Tablets)

    CredaERP tracks stock at the tablet level to prevent math errors. If a strip has 10 tablets:

    • To sell 1 Strip: Type 10 OR type 1+0 (1 strip + 0 loose).
    • To sell 2 Strips and 4 loose tablets: Type 2+4. The system mathematically deducts 24 tablets from the master stock without breaking the strip inventory.
    TAB 2

    📜 Invoice History

    This tab is a digital copy of every bill generated in your pharmacy.

    Key Functionalities:
    • Reprinting: (Real World Example: The power cuts exactly as you hit Save. The bill is saved, but the thermal printer dies. Don't re-bill! Just go to Invoice History, find the top bill, and click Reprint.)
    • Cancellation: If a cashier bills the wrong item, they can cancel the invoice here. Note: You can only cancel an invoice if the Day Closure for that date has not been completed. Once the day is locked, you must issue a Sales Return instead.
    TAB 3

    🔄 Return Invoice (Credit Notes)

    Handling returned medicines legally and safely.

    Key Functionalities:
    • Load by Bill No: Enter the original invoice number, and CredaERP loads the exact items, batches, and prices the customer originally paid.
    • Partial Returns: (Real World Example: A patient bought a full strip of 10 tablets, but the doctor stopped the medication after 3 days. The patient returns 7 loose tablets. You load the bill, type 7 in the return quantity, and save.)
    • Financial & GST Impact: The system automatically puts 7 tablets back into physical stock, decreases today's revenue, and generates a GST Credit Note to legally reduce your tax liability for the month.
    TAB 4

    🛠️ Modify / Cancel Return

    The history tab specifically for Sales Returns.

    • Audit Trail: View every Credit Note generated by your staff to prevent return-fraud (where cashiers fake a return and pocket the cash).
    • Reprint Credit Notes: If a B2B clinic requires a physical copy of the GST Credit Note for their records, reprint it here.
    TAB 5

    👥 Customer Master (CRM)

    A built-in CRM and Ledger system for managing chronic patients or B2B clinics.

    Deep-Dive Functionalities:
    • Credit Ledgers (Udhaar): (Real World Example: A local family buys medicines on credit all month. You bill them using the "Credit" payment type. At the end of the month, go to the Customer Master, open their profile, see they owe Rs. 4,500, and click Receive Payment when they hand you the cash. It updates the ledger instantly.)
    • Default Discounts: You can edit a chronic patient's profile and set a "Default Discount %". Every time they are selected on the billing screen, the system automatically applies their special discount.
    • GSTIN Linking (B2B): Essential for wholesale billing. Save the clinic's GSTIN here so it automatically prints on their Tax Invoices, allowing them to claim ITC.
    • Purchase History Tracking: View a specific customer's entire lifetime purchase history. Useful for checking what brand of medicine they bought 3 months ago if they forgot the name.

    3. Executive Dashboard & Analytics

    The moment you log into CredaERP, you are greeted by the Executive Dashboard. This is your real-time analytics command center. It instantly computes thousands of database transactions to give you a live health check of your pharmacy without needing to run any manual reports.

    KPIs

    Key Performance Indicators (Top Row)

    • Today's Sale vs Purchase: Tracks cash flow direction for the current day.
    • Estimated Gross Profit: (Magic Metric) CredaERP calculates the exact landing cost of the specific batches you sold this month and deducts it from your sales revenue, giving you a highly accurate, real-time profit estimate.
    • Held Sales: Warns you if cashiers have suspended bills that haven't been completed.
    • Value at Risk (EXP): Converts your expiring stock count into a monetary loss figure (e.g., "₹ 4,500 at risk"). This tells you exactly how much cash you will lose if you don't process a Purchase Return to the distributor.
    GRAPHS

    Visual Analytics (Charts)

    • Monthly Revenue Analytics: A 30-day trendline showing your daily sales volume. Use this to identify peak shopping days (e.g., recognizing that Mondays are always your highest volume day).
    • Payment Collection Split (Pie Chart): A visual breakdown of Cash vs UPI vs Card payments. Useful for tracking digital adoption by your customers.
    • Fast Moving Items: A bar chart ranking your top-selling medicines over the last 30 days. Use this to negotiate better bulk-purchase discounts with distributors for these specific items.
    • Top Prescribing Doctors: Ranks which local clinics are sending you the most prescriptions. Extremely valuable for building relationships with local doctors.
    ALERTS

    Actionable Data Grids

    The bottom of the dashboard features two grids that require your daily attention:

    • Recent Transactions: A live feed of what your cashiers are billing right now.
    • Critical — Expiring Stock: An automatic alert listing medicines that will expire in the next 30 days. You should click this list and physically pull these bottles from the shelf every morning.

    4. Procurement Workspace (Purchases & Vendors)

    The Procurement module (F2) handles your inbound distributor invoices, stock increases, and Vendor Ledgers. It contains 4 major tabs.

    TAB 1

    🛒 Purchase Entry (Distributor Invoices)

    This is where you log new stock arriving at your shop. CredaERP provides two distinct ways to procure stock: Manual Entry and Smart AI Scanning.

    🤖 Procurement via AI (Smart Scan)

    Instead of manually typing 50 rows of medicines from a distributor's paper bill, you can let CredaERP's AI do the heavy lifting.

    1. Ensure your Gemini API Key is configured in System Settings → Integrations.
    2. In the Purchase Entry tab, click the Scan Invoices button.
    3. Upload a photo or PDF of the physical distributor bill.
    4. AI Extraction The Invoice Scanner Service processes the document and automatically extracts the Vendor Name, Invoice Number, Date, Medicines, Batches, Expiries, Quantities, and GST totals.
    5. Review the extracted data grid on the screen, fix any typos, and hit Save. Your stock is instantly updated!
    Manual Entry Functionalities:
    • Smart GST Calculation: Once you select a vendor, enter the Invoice No and Date. As you manually add medicines, CredaERP automatically calculates the Input Tax Credit (ITC). Before saving, verify that the Calculated Total on the screen exactly matches the total on the distributor's paper bill.
    • Handling Free Schemes (e.g., Buy 10 Get 2): (Real World Example: The distributor gives you 2 free bottles of cough syrup. In the grid, type 10 in Qty, and 2 in Free Qty. CredaERP adds 12 bottles to your physical shelf, but calculates your Purchase Landing Cost based only on the 10 paid bottles, correctly increasing your profit margin when you sell them.)
    • MRP vs Purchase Rate Safety Check: If a data-entry operator accidentally types a Purchase Rate that is higher than the MRP, the system blocks the save to prevent illegal pricing logic.
    TAB 2

    📋 Orders & Returns

    Manage outbound returns to the distributor.

    • Purchase Returns (Debit Notes): (Real World Example: You pull 5 expired strips of Azithromycin from the shelf. You create a Purchase Return here. The system deducts the 5 strips from your stock, reduces your Vendor Payable ledger, and generates a GST Debit Note to reverse the ITC you claimed when you bought them.)
    • Purchase Orders (PO): Draft automated Purchase Orders based on the Reorder Alerts report, and send them to distributors. When the stock arrives, click Receive Against PO in Tab 1 to automatically convert the PO into an inward purchase bill.
    TAB 3

    📊 Registers

    Your Purchase Audit Trail.

    • Purchase Register: A chronological ledger of every distributor invoice entered. If your CA asks for your "Purchase Book", this is what you export.
    TAB 4

    🏭 Vendor Master

    The centralized hub for your distributors and Payable Ledgers.

    Deep-Dive Functionalities:
    • Comprehensive Profiles: Store the vendor's GSTIN, State Code (for IGST vs CGST/SGST calculation), Drug License Number (DL No), and WhatsApp Mobile Number (crucial for automated PO sending).
    • Automated Payable Ledgers: Every time you save a Purchase Entry on Credit, the Vendor's outstanding balance increases. Every time you create a Purchase Return, the balance decreases automatically.
    • Paying Distributors: (Real World Example: Your vendor 'Apollo' has a balance of Rs. 50,000. You write them a cheque for Rs. 20,000. Open their profile here, click Add Payment, select 'Bank', and enter 20,000. Their outstanding balance instantly drops to Rs. 30,000.)

    4.5. End-to-End Smart Procurement (Shortage to WhatsApp)

    CredaERP features an incredibly powerful, semi-automated procurement pipeline. Instead of writing medicine names on a piece of paper and calling distributors, you can manage the entire lifecycle digitally—from detecting a shortage to WhatsApping the Purchase Order (PO), to automatically receiving the stock.

    The 5-Step Smart Procurement Workflow

    STEP 1

    Creating a Shortage

    A "Shortage" is an internal list of medicines you need to buy. There are two ways items get added to this list:

    • Automatic Creation: Every night, CredaERP runs the Reorder Alerts engine. If a medicine drops below its minimum threshold, it is automatically added to the Shortage list.
    • Manual Creation: If a customer asks for a medicine you don't stock, press F11 anywhere in the software to instantly open the Quick Shortage Entry window. Type the name, enter the quantity, and hit save.
    STEP 2

    Assigning Vendors to Shortages

    Go to the Shortage Processing screen.

    • You will see a list of all your needed medicines.
    • In the Vendor column, click the dropdown to assign a specific distributor to each medicine.
    • (Example: You assign 5 Cipla medicines to 'Apollo Distributors' and 2 Sun Pharma medicines to 'Metro Pharma'.)
    STEP 3

    Generating the Purchase Order (PO)

    Once your vendors are assigned, click the Process Selected button.

    • CredaERP automatically groups the medicines by Vendor.
    • It instantly generates official, numbered Purchase Orders (POs) for each distributor (e.g., PO-1001 for Apollo, PO-1002 for Metro).
    STEP 4

    WhatsApping the PO Automatically

    You don't need to call the distributor!

    1. Go to the Orders & Returns tab (Purchase Order History).
    2. Select the PO you just generated.
    3. Click the Send via WhatsApp button.
    4. Automation CredaERP connects to the WhatsApp API, pulls the vendor's registered mobile number from the Vendor Master, formats a beautiful text-based Purchase Order, and sends it directly to their phone!
    STEP 5

    Receiving the PO (Full or Partial)

    When the distributor's delivery boy arrives at your shop with the physical boxes:

    1. Go to the Purchase Entry tab.
    2. Click the Receive Against PO button and select the PO number.
    3. CredaERP instantly fills the purchase grid with the expected medicines and quantities.
    4. Full Receipt: If they brought everything, just enter the batch numbers, check the GST, and hit Save.
    5. Partial Receipt: (Real World Example: You ordered 10 strips, but they only had 6 in stock.) Simply change the quantity in the grid from 10 to 6 and hit Save. CredaERP will mark the PO as "Partially Fulfilled" so you know they still owe you 4 strips!

    ACTION

    Key Functionalities:

    6. Deep Dive: Returns, Reversals & ITC Impact

    Returning stock is the most complex operation in an ERP because it simultaneously touches Inventory, General Ledger Accounting, and Government GST Compliance. CredaERP handles all of this automatically, but you must use the correct screens.

    A. Sales Returns (Customer returning medicine to you)

    When a patient returns a medicine, you must use the Sales Return screen (also known as a Credit Note in GST terms).

    What happens under the hood when you process a Sales Return:

    • Inventory Impact: The exact quantity (e.g., 4 loose tablets) is immediately added back to the specific Batch's physical stock.
    • Accounting Impact: Your daily revenue is decreased. If they paid Cash, your cash drawer expected balance drops. If it was a Credit Sale, the customer's outstanding balance drops.
    • GST Impact: A Credit Note is generated against the original B2C/B2B invoice. This automatically reduces your Output Tax Liability for the current month's GSTR-1.

    💡 Scenario: Returning medicine from a previous closed month

    If a customer returns a medicine bought in March, but it is now May (and March GST is already filed), DO NOT try to delete or alter the old March invoice. The GST portal will reject it. Process a standard Sales Return today. CredaERP will date the Credit Note for May, which legally reduces your May tax liability, keeping you 100% compliant with GST laws.

    B. Purchase Returns (You returning medicine to a Distributor)

    When you return expired or damaged stock to a distributor, you must use the Purchase Return screen (also known as a Debit Note).

    What happens under the hood when you process a Purchase Return:

    • Inventory Impact: The stock is deducted from your shelf.
    • Accounting Impact: The system decreases your Vendor Payable balance (meaning you owe the distributor less money).
    • GST Impact (ITC Reversal): Because you initially claimed Input Tax Credit (ITC) when you bought the medicine, returning it means you must give that tax credit back to the government. CredaERP automatically records an ITC Reversal via a Debit Note, which will correctly populate in your GSTR-3B under "ITC Reversed".
    ⚠️ Warning: Stock Adjustment vs Purchase Return

    If a bottle breaks on your floor, do NOT use Purchase Return. A Purchase Return tells the government that the distributor took the bottle back and refunded you. If the bottle is just broken, use Inventory → Stock Adjustment. This writes off the cost as a business loss but does NOT attempt to reverse the GST ITC.

    10. Day Closure (EOD) Master Guide

    The Day Closure (End of Day) routine is the financial heartbeat of your pharmacy. It ensures that the physical cash in your drawer matches the digital ledger, and it cryptographically locks the day's invoices to prevent tampering. You must perform Day Closure every single night.

    ⚠️ Stale Shift Lock (Forgot to close yesterday?)

    If you leave the pharmacy in a hurry and forget to close the day, CredaERP will automatically detect a "Stale Shift" the next morning. All billing and purchasing will be completely blocked until you run the Day Closure for the previous date. This strict rule prevents financial data from bleeding across different calendar dates.

    The 4-Step EOD Workflow

    STEP 1

    Pre-Flight Validation

    Go to MAINTENANCE → Day Closure (EOD). Before the system even lets you start counting cash, it runs a pre-flight check on your active shift.

    The EOD will be BLOCKED if:

    • You have Held/Suspended Bills: If a cashier suspended a bill during rush hour and forgot about it, you must recall it in the POS (F1) and either complete the sale or cancel it.
    • You have Pending Advance Orders: All advance orders scheduled for today must be marked as fulfilled or cancelled.
    STEP 2

    Cash Drawer Reconciliation

    Once pre-flight passes, the screen will show you the Expected Cash. This is calculated as:

    (Morning Opening Balance) + (Cash Sales) + (Customer Credit Collections) - (Vendor Payments) - (Shop Expenses)

    1. Empty your physical cash drawer.
    2. Count every note and coin.
    3. Type the actual physical total into the Actual Cash box.
    STEP 3

    Digital Settlement (Card / UPI)

    Do not just assume the UPI machine matches the software.

    1. Print the "Batch Settlement Slip" from your physical Card/UPI swiping machine (e.g., PineLabs / Paytm Soundbox).
    2. Compare the total on the printed slip with the Expected UPI/Card on the CredaERP screen.
    3. If they match, you are perfectly reconciled. If they don't, check Invoice History to see if a cashier clicked "Cash" when the customer actually paid via UPI.
    STEP 4

    Handle Shortages & Lock the Day

    If your actual cash is Rs. 50 less than the expected cash, CredaERP will highlight the difference in red. You cannot close the day with an unexplained difference.

    • To fix a shortage: Did you buy tea for the staff and forget to enter it? Go to FINANCIALS → Journal Voucher and add a Rs. 50 expense. Come back to EOD, and the expected cash will drop to match your physical cash.
    • Locking: Once the difference is 0, click Close Day. The system will securely lock all invoices, seal the ledger, and log out the shift.

    11. DIY Guide: How to File Your Own GST (No CA Required)

    CredaERP is designed so intuitively that pharmacy owners can bypass expensive CA fees and file their own GST returns directly. The Government GST portal requires two main filings every month (or quarter): GSTR-1 (Your Sales) and GSTR-3B (Your Tax Payment).

    💡 The Golden Rule of GST

    Before you begin filing, you MUST finish entering all your purchase bills for the month, and you MUST complete your Day Closure for the last day of the month. Never file GST if you have pending data entry.

    Step-by-Step Filing Workflow

    STEP 1

    Fix Data Errors (Correction Center)

    Go to FINANCIALS → GST Filing → Correction Center.

    CredaERP automatically scans your entire database for the selected month. If you accidentally entered a 14-digit GSTIN instead of 15 digits, or sold a B2B invoice to a clinic but forgot their GSTIN, the Correction Center will list it here.

    • Action Required You must resolve all Red (High Severity) warnings before proceeding. The GST portal will reject your file if these exist.
    • Simply click on the error, fix the value, and save.
    STEP 2

    Reconcile Vendor Bills (GSTR-2B)

    You need to check if the distributors you bought from actually paid their taxes to the government. If they didn't, the government won't give you Input Tax Credit (ITC).

    1. Log in to the Government GST Portal.
    2. Download the GSTR-2B JSON file for the month.
    3. Open CredaERP, go to FINANCIALS → GST Filing → Reconciliation.
    4. Upload the JSON file.
    5. Magic Happens CredaERP will match the portal file against your local purchase entries. It will show you a list of Missing Invoices (Vendor didn't upload) and Mismatches (Vendor uploaded Rs. 1000, but you entered Rs. 1200).
    6. Call the defaulting vendors and tell them to fix their uploads.
    STEP 3

    Generate & Upload GSTR-1 (Your Sales)

    GSTR-1 tells the government exactly what you sold. It must be filed by the 11th of the next month.

    1. In CredaERP, go to FINANCIALS → GST Filing → GSTR-1 Details.
    2. Select the month and click Generate GSTR-1.
    3. Review the summary on the screen. (B2C sales are grouped together, B2B sales are listed invoice-by-invoice).
    4. Click Export JSON.
    5. Log in to the Government GST Portal, go to Returns Dashboard → GSTR-1 → Prepare Offline.
    6. Upload the JSON file you just exported from CredaERP. Submit and File!
    STEP 4

    File GSTR-3B (Tax Payment)

    GSTR-3B is where you actually pay the tax. It must be filed by the 20th of the next month. The government auto-populates this form based on your GSTR-1 (Output Tax) and GSTR-2B (Input Tax).

    1. In CredaERP, go to FINANCIALS → GST Filing → GSTR-3B Summary.
    2. This screen shows you what your books say you owe. Total Tax on Sales minus Total Tax on Purchases.
    3. On the Government GST Portal, open the GSTR-3B form.
    4. Crucial Check Compare the numbers on the Government Portal with the numbers on the CredaERP screen. They should match perfectly. (Minor penny differences are normal due to rounding).
    5. If everything matches, generate the Challan on the portal and pay the net tax amount via net banking.

    Understanding the CA Dashboard

    Even if you file yourself, the CA Dashboard is highly useful for owners. It provides a real-time health check:

    • Net GST Payable: Tells you exactly how much cash you need to keep in your bank account for the 20th of next month.
    • Tax Distribution Chart: Shows what percentage of your sales fall under 12% vs 18% GST.

    💡 Scenario: QRMP Scheme (Quarterly Filers)

    If your pharmacy has a turnover below Rs. 5 Crore, you might be on the QRMP scheme (Quarterly Return Filing and Monthly Payment). Instead of filing GSTR-1 every month, you only file it every 3 months. However, in Month 1 and 2, you must use the IFF (Invoice Furnishing Facility) tab in CredaERP to upload only your B2B sales (sales to clinics) so they can claim ITC. Use the PMT-06 tab to calculate your monthly challan payment.

    13. Disaster Recovery: Backup & Restore

    Hardware fails. Hard drives crash. Ransomware happens. Your data is your business.

    🛡️ Best Practice: The 3-2-1 Backup Rule

    At the end of every day, go to System Settings → Database → Create Backup. Save the file to your computer. Then, immediately copy it to a USB Pen Drive (Local Copy) AND upload it to Google Drive (Cloud Copy).

    💡 Scenario: Performing a Database Restore

    If your computer crashes and you buy a new one, install CredaERP, go to Database settings, and click Restore Backup.

    CRITICAL POST-RESTORE REQUIREMENT: The restore process drops and replaces every table in the PostgreSQL database in the background. Once the success message appears, the database locks are volatile. You MUST close CredaERP completely and restart it. If you attempt to process a sale immediately after clicking Restore without restarting, the application will deadlock.

    14. Support & Diagnostics Center

    When something goes wrong—whether it's a slow database, a failing backup, or a strange error—CredaERP provides a built-in diagnostic tool to help the support team fix your issue instantly. You can find this tool in MAINTENANCE → System Settings → Support & Diagnostics.

    Step-by-Step Guide to the Diagnostics Tab

    STEP 1

    Check the Application Health Status

    At the top left of the screen, the system constantly monitors its own vitals. Click the Refresh Status button.

    • Database Status: Confirms if the PostgreSQL engine is running and responding to queries.
    • Backup Health: Checks if your last backup was completed successfully within the last 24 hours. (If this is red, your data is at risk!)
    STEP 2

    Generating a Support Bundle

    If you need to contact CredaERP technical support, they will ask you for a "Support Bundle". This is a secure ZIP file containing error logs and system configurations.

    1. Locate the Diagnostic Actions section on the right side of the screen.
    2. Select the Log Range from the dropdown (e.g., "Last 24 Hours" or "Last 7 Days"). Only select what the support agent requests to keep the file size small.
    3. Click the blue Export Support Bundle button.
    4. Save the ZIP file to your Desktop and email it to credaerp@gmail.com or send it via WhatsApp.

    Note: The diagnostic output console below the button will show you exactly what is being zipped. It is strictly technical data; no patient or financial data is exposed.

    STEP 3

    Disaster Recovery: Rehash Checkpoints

    You will see an orange button labeled 🔐 Rehash DR Checkpoints.

    ⚠️ Admin Only Action

    CredaERP uses cryptographic hashing to protect your invoices from being tampered with. If an authorized support agent has to manually repair a corrupted database table on your computer, the system will detect the change and trigger a "Tamper Alert". Clicking this button re-signs the database hashes, telling the system that the manual changes were authorized. Do not click this unless instructed by Support.

    STEP 4

    Remote Assistance (Help Desk)

    In the bottom-left corner, the Help Desk Details box displays the current support contact details. When instructed, please open AnyDesk or RustDesk on your computer and provide the ID to the support agent so they can securely remote into your system to resolve the issue.

    • Count the physical loose cash in the drawer and ensure it matches the Opening Balance shown on the Dashboard.

    • Go to Day Closure (EOD).
    • Count your physical cash. Compare it to the Expected Cash in the system.

    If you rush home and forget to run Day Closure, the next morning the system will warn you that the previous day is still open. Simply run the Day Closure for the previous date before generating any new bills. The system handles date boundaries safely.

    18. Frequently Asked Questions (FAQ)

    Can I use CredaERP if the internet goes down?

    Absolutely. CredaERP is designed as an offline-first desktop application. The PostgreSQL database runs directly on your local hard drive. You can continue billing, purchasing, and managing stock without an internet connection. Internet is mainly required for software updates and any online support or connected services you choose to use.

    What do I do if a customer returns medicine from 2 months ago?

    First, verify your pharmacy's return policy. If you accept it, use the Sales Return screen. Since the financial month is already closed and GST filed, the system will generate a Credit Note for the current month, which will automatically adjust your current month's GST liability downward. Do not try to delete the old invoice!

    A patient wants a custom discount on a specific bill, how do I apply it?

    On the POS screen, beneath the item grid, there is a Bill Discount field. You can enter an absolute amount (e.g., Rs. 50 off) or a percentage (e.g., 5%). The system will automatically prorate this discount across all taxable items to ensure the GST calculations remain mathematically compliant.
